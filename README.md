# Student Hub

Адаптивний веб-застосунок з frontend та backend (Node.js + Express).

## Функціонал
- Адаптивний інтерфейс (Flexbox + Grid)
- Бургер-меню для мобільних пристроїв
- REST API
- Анімації та hover-ефекти

## Запуск проєкту

```bash
npm install
node html/index.html
```
## Структура
HTML / CSS / JS розділені по папках

## Git workflow
- main - фінальна версія
- develop - розробка
